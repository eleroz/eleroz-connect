# ЭЛЕРОЗ Коннект

Программа удалённой помощи [ЭЛЕРОЗ](https://eleroz.ru/udalennaya-pomoshch/).

Основана на [RustDesk](https://github.com/rustdesk/rustdesk) версии 1.4.9 и распространяется
на тех же условиях — GNU Affero General Public License v3 (файл `LICENCE`).
Авторские права на RustDesk принадлежат Purslane Tech Pte. Ltd. и участникам проекта.

## Что изменено

Все изменения — коммиты в ветке `eleroz` поверх тега `1.4.9`:

- название «ЭЛЕРОЗ Коннект»; техническое имя `ElerozConnect` (служба, папки, каналы связи);
- сервер ЭЛЕРОЗ `connect.eleroz.com` и его публичный ключ встроены в программу —
  через скрипт `eleroz/brand_hbb_common.py`, который перед сборкой правит подмодуль `libs/hbb_common`;
- фирменные цвета и значки ЭЛЕРОЗ;
- окно «О программе» и ссылки ведут на eleroz.ru;
- файл программы `elerozconnect.exe`; ярлыки, папка в меню «Пуск» и запись
  в «Программах и компонентах» — «ЭЛЕРОЗ Коннект», издатель — ЭЛЕРОЗ;
- у самораспаковывающегося файла сведения ЭЛЕРОЗ;
- собственные сценарии сборки RustDesk для всех платформ удалены, оставлена сборка Windows x64.

## Сборка

Actions → «ЭЛЕРОЗ Коннект — сборка Windows x64» → Run workflow.
Готовый самораспаковывающийся файл `ElerozConnect-<версия>-b<номер сборки>-x64.exe` —
в артефакте `eleroz-connect-windows-x64` этого запуска.
