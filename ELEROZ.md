# ЭЛЕРОЗ Коннект

Программа удалённой помощи [ЭЛЕРОЗ](https://eleroz.ru/udalennaya-pomoshch/).

Основана на [RustDesk](https://github.com/rustdesk/rustdesk) версии 1.4.9 и распространяется
на тех же условиях — GNU Affero General Public License v3 (файл `LICENCE`).
Авторские права на RustDesk принадлежат Purslane Tech Pte. Ltd. и участникам проекта.

## Что изменено

Все изменения — коммиты в ветке `eleroz` поверх тега `1.4.9`:

- название «ЭЛЕРОЗ Коннект»; техническое имя `ElerozConnect` (служба, папки, каналы связи);
- сервер ЭЛЕРОЗ `connect.eleroz.com` и его публичный ключ встроены в программу —
  через скрипт `eleroz/brand_hbb_common.py`, который перед сборкой правит подмодуль `libs/hbb_common`;
- фирменные цвета и значки ЭЛЕРОЗ;
- окно «О программе» и ссылки ведут на eleroz.ru;
- файл программы `elerozconnect.exe`; ярлыки, папка в меню «Пуск» и запись
  в «Программах и компонентах» — «ЭЛЕРОЗ Коннект», издатель — ЭЛЕРОЗ;
- подписи окон по-русски: «ЭЛЕРОЗ Коннект — подключение», «ЭЛЕРОЗ Коннект — установка»;
  ярлык автозапуска — «ЭЛЕРОЗ Коннект (автозапуск)»;
- у самораспаковывающегося файла сведения ЭЛЕРОЗ;
- переносная версия распаковывается в свою папку `%LOCALAPPDATA%\elerozconnect-portable`;
- установщик MSI: те же названия, тексты мастера по-русски, в окне лицензии — условия ЭЛЕРОЗ;
- постоянный доступ одной кнопкой в главном окне и встроенная инструкция (кнопка «?»);
- адресная книга, учётная запись и группы убраны — это функции платного сервера RustDesk;
- обновление со своего сайта: программа читает `https://eleroz.ru/upload/eleroz-connect/update.json`,
  сравнивает номер сборки со своим, скачивает файл и сверяет контрольную сумму;
- собственные сценарии сборки RustDesk для всех платформ удалены, оставлена сборка Windows x64.

## Сборка

Actions → «ЭЛЕРОЗ Коннект — сборка Windows x64» → Run workflow. Артефакты запуска:

- `eleroz-connect-windows-x64` — самораспаковывающийся `ElerozConnect-<версия>-b<номер сборки>-x64.exe`;
- `eleroz-connect-windows-x64-msi` — пакет `ElerozConnect-<версия>-b<номер сборки>-x64.msi`
  для установки через доменные политики (`msiexec /i <файл> /qn`);
- `eleroz-connect-update-json` — `update.json` для сайта: номер сборки, ссылки, контрольные суммы;
- `eleroz-connect-windows-x64-folder` — та же программа папкой, без упаковки.

Выпуск версии: положить exe, msi и `update.json` в `/upload/eleroz-connect/` на сайте —
установленные программы найдут обновление сами. Скрипты проверки сборки — `eleroz/tools/`.

Сценарий «ЭЛЕРОЗ Коннект — MSI из готовой сборки» собирает только MSI, беря папку программы
из указанного запуска: упаковка занимает минуты, программа при этом не пересобирается.
