# Инструменты проверки сборки

Скрипты для Windows PowerShell 5.1 (`powershell.exe`, не `pwsh`): им нужен System.Drawing,
а в PowerShell 7 он подключается не так. Скрипты только читают и снимают экран,
в систему ничего не ставят.

| Скрипт | Что делает |
|---|---|
| `read-msi.ps1 -Msi <файл>` | Читает таблицы MSI, не устанавливая его: название, издатель, язык, папки, ярлыки, запись в «Программах и компонентах», служебные действия. |
| `capture-window.ps1 -OutPath <файл.png>` | Находит окно запущенной переносной копии (`%LOCALAPPDATA%\elerozconnect-portable`) и сохраняет снимок. Печатает коды символов заголовка, чтобы проверить кириллицу. |
| `resize-and-capture.ps1 -OutPath <файл.png> -Width 860 -Height 1000` | То же, но сначала растягивает окно, чтобы влезли карточки внизу левой панели. |

Щелчки по окну из скриптов Flutter не принимает: сообщения мыши он обрабатывает
по-своему. Диалоги (инструкцию, мастер постоянного доступа) открывать руками.

Перед запуском проверочной копии на компьютере, где уже стоит ЭЛЕРОЗ Коннект или
RustDesk, подмените сервер в тестовом конфиге — иначе копия займёт номер компьютера
на боевом сервере. Порядок — в документации проекта, раздел «Сборка и выпуск версии».
